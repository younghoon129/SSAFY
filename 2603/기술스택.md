## Supabase
- 자유도, SQL
    - 벤더 락인 방지
    - SQL의 강력함 필요
- 오픈 소스 대안(The Open Source Alternative)
- 최근 떠오르는 강력한 트렌드
- Firebse와 유사한 기능 제공
- 관계형 데이터베이스(REDBMS) 기반
- 벤더 락인(Vendor Lock-in) 없음
- PostgreSQL 기반이라는 강력한 안정성
    - 팀의 공용어 = SQL
    - 데이터 분석, 리포팅 확장성 보장
    - 설계의 흔적 이 남는 데이터 레이어
- 벤더 종속성 걱정 끝
    - 오픈소스 기반
    - 언제든 떠날 수 있는 구조(Export/Self-hosting)
    - 플랫폼에 끌려가지 않는다는 안정감
- 저렴

## Next.js - 하나의 완전한 웹 애플리케이션
- React 기반 프론트엔드
- Node.js 런타임 서버 연산
- 파일 기반 라우팅
    - 폴더가 곧 주소가 됨
- API 라우트 - 나만의 백엔드 엔드포인트
    - API 폴더 내 ROUTE.TS 생성
    - 폴더 이름이 곧 엔드포인트 경로
    - GET, POST 등 다양한 HTTP 메서드 활용
- Databsae의 Row Level Security 활용
    - 데이터베이스 시스템의 세밀한 접근 제어
    - 사용자의 신원, 역할 또는 실행 컨텍스트에 따라 테이블의 특정 행에 대한 접근 통제
    - 행 수준에서 ㄷ이터 접근 엄격히 제한
    - 보안 정책의 투명한 실행
    - 애플리케이션이 아닌 데이터베이스 중아에서 접근 논리 관리

- CSR/SSR, SEO
    - CSR(Client Side)
    - SSR(Server Side)
    - 미리 렌더링된 HTML을 제공하여 검색 봇이 내용을 읽을 수 있음
        - SEO 작업 유리

- Hydration Rendering
    - 서버에서 완전한 HTML 전송
    - 페이지 표시(몇 초간 상호작용 불가)
    - 브라우저가 Javascript 다운로드 및 결합
    - 즉각적이고 빠른 네비게이션 완성
