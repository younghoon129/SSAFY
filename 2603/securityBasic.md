# 기본 보안
## Network
- OSI 7 Layer
- TCP/IP 4 Layer

## ARP
- 네트워크 상에서 IP 주소를 물리적 네트워크 주소(MAC)로 대응(bind)시키기 위해 사용되는 프로토콜
- 목적지 IP의 장비가 소유한 MAC 주소를 알아내어 전송하기 위함

## HTTP Get Flooding Attack
- 수 많은 요청을 보내서 서버를 과부하 시키는 DOS 및 DDOS 공격
- 서버로 수 많은 HTTP Get Request를 보내서 서버의 자원을 모두 소비하도록 과부하 시키면 일반 사용자가 서비스 요청에 응답해줄 수 없는 상황이 됨
- 보안 대책
    - 임계치를 설정하고 비정상적 트래픽을 유발하는 IP를 차단

## Slowloris DDoS Attack
- OSI 모델의 레이어 7을 대상으로 하는 분산 서비스 거부 공격
- 대상 FQDN에 대한 많은 동시 TCP 연결을 열고 유지하고 낮은 속도 및 양의 HTTP 요청 또는 연결된 세션당 HTTP 연결을 생성하여 단일 컴퓨터, 웹 서버, 데이터베이스 또는 API를 압도하도록 설계
- 대책
    - 단일 IP 주소가 열도록 요청할 수 있는 연결 수를 제한해야 함
    - 모든 연결에 허용되는 최소 전송 속도를 높여야 함
    - 클라이언트가 연결 상태를 유지할 수 있는 시간을 제한해야 함
    - 서버가 허용하는 최대 클라이언트 수를 늘려야 함
