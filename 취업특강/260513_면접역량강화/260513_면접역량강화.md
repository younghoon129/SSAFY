# 면접역량강화
- 직무별 cs 기반 면접
    - 프론트
        - 사용자 경험 관점에서 본인의 기술적 선택이 어떤 가치를 만들었는지 증명
            - 구체적인 레퍼런스나 자료를 기준으로 객관적으로 하는 게 좋음
        - 프레임워크 숙련도보다 브라우저 동작 원리와 자바스크립트 기본기에 집중하여 답변
        - 다양한 기기와 브라우저 환경에서도 안정적으로 동작하는 개발 태도를 강조
    - 백엔드
        - 특정 기술 도입 시 얻은 이득과 포기한 기회비용을 논리적 근거로 설명
            - 기준점 제시 및 판단력을 볼 수 있음
        - 정상 작동보다 예외 상황에서 데이터 정합성을 유지하기 위한 해결 역량을 강조
        - 현재의 기능 구현을 넘어 대규모 트래픽 확장과 유지보수를 고려한 설계 경험 강조
    - AI/DATA
        - 모델 설명보다 문제 정의와 feature 설계 중심으로 답변
        - 데이터 전처리, feature 선택 이유를 구체적으로 설명
        - 성능 개선은 실험 과정(A/B, 비교 기준) 중심으로 전달
        - 결과는 단순 수치가 아닌 '왜 개선됐는지' 까지 설명
        - 한계 상황과 개선 방향까지 함께 제시
    - 임베디드
        - HW,SW 통합 관점에서 문제 해결 과정 중심으로 설명
        - 센서, 통신 설계 시 선택 기준과 실제 적용 이유 강조
        - 성능/안정성 이슈 발생 시 원인 분석과 개선 과정 포함
        - 동시성 문제는 실제 구현 경험(Mutex, 세마포어 등) 기반 설명
        - 시스템 전체 흐름(인터럽트, 메모리, 제어 흐름) 이해 기반으로 답변
